# NPC 파츠 이미지

모든 이미지는 위치 조정이 필요 없는 32x32 투명 PNG로 저장합니다.

아래 파일명을 사용합니다.

- `back_hair/back_hair_01.png` ~ `back_hair_03.png`
- `bottom/bottom_01.png` ~ `bottom_03.png`
- `top/top_01.png` ~ `top_04.png`
- `face/face_01.png`
- `eyes/eyes_01.png` ~ `eyes_04.png`
- `front_hair/front_hair_01.png` ~ `front_hair_03.png`

합성 순서는 아래에서 위로 뒷머리, 하의, 상의, 얼굴, 눈, 앞머리입니다.

앞머리와 뒷머리는 각각 25% 확률로 출력하지 않습니다.
