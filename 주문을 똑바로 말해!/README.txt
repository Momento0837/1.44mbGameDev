# 주문을 똑바로 말해!

### 한줄 설명
- 주문을 제대로 하지 않는 손님들. 주문을 추리하여, 원하는 음식을 만들어내는 추리형 요리 게임.

### 플레이 방법
1.  NPC의 주문을 듣는다.
2.  나레이션 박스를 클릭하여 추가 주문을 듣는다.
3.  재료 위에 호버링하며 힌트를 확인한다.
4.  주문에 따라 재료를 클릭하여 조리한다.
5.  도마 위에 있는 재료를 클릭하면 제거할 수 있다.

### 게임 특징

• 주문을 듣는 것이 곧 퍼즐
—♪ 손님의 애매한 표현, 말 바꾸기, 불필요하게 긴 설명과 숨겨진 조건을 읽어 실제로 원하는 메뉴를 파악해야 합니다.

• 재료를 직접 골라 완성하는 요리 시스템
—♪ 주문을 해석한 뒤 또띠아, 채소, 김과 밥, 심지어 민트초코까지 다양한 재료를 직접 선택해 음식을 만듭니다.

• 손님마다 달라지는 주문 방식
—♪ 평범한 주문부터 재료의 순서를 따지는 손님, 주문을 번복하는 손님, 지나치게 많은 것을 요구하는 손님 등 서로 다른 방식의 주문이 등장합니다.

• 말 속에서 찾아내는 추가 힌트
—♪ 주문만으로 확신할 수 없다면 추가 대사를 듣거나 재료에 반응하는 손님의 말을 살펴보며 정답을 추론할 수 있습니다. 단, 손님이 언제나 친절하게 정답을 말해 주지는 않습니다.

• 정확도가 곧 매출로 이어지는 영업
—♪ 잘못 넣은 재료가 많을수록 받을 수 있는 금액이 줄어들며, 매일 주어지는 목표 매출을 달성해야 다음 영업을 이어갈 수 있습니다.

• 1.44MB를 목표로 한 초소형 게임
—♪ Win32 기반의 직접 구현과 저용량 픽셀 리소스를 활용해, 게임 전체를 1.44MB라는 극단적으로 작은 용량 안에 담는 것을 목표로 제작되었습니다.
